# Perspektive

**`Panorama`** is an unofficial [perspektive](https://github.com/r0yzer/perspektive) fork for NeoForge. Look around while locking your head rotation, so you can move your camera around without change the direction at where you are looking at.

Don't report any issues to the source repository, as [r0yzer](https://github.com/r0yzer) is in no shape or form affiliated with Panorama's development. Any questions may otherwise be inquired at either this repository's [issues](https://github.com/OyasumiLiv/panorama/issues) or [discussions](https://github.com/OyasumiLiv/panorama/discussions) pages.
## Development / Build

### Windows
```sh 
git clone https://github.com/OyasumiLiv/panorama.git
cd panorama
gradlew.bat build
```
### MacOS/Linux
```sh
git clone https://github.com/OyasumiLiv/panorama.git && cd panorama
./gradlew build
```
## Releases

Panorama can be found at [Modrinth](https://modrinth.com/mod/panorama/) or the [releases](https://github.com/OyasumiLiv/panorama/releases) page.

To access the settings GUI install [ModMenu](https://modrinth.com/mod/modmenu) and click on the "configure" button.
